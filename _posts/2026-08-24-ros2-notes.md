整理 Ubuntu 上安装 ROS 2、编译工作空间和常用命令。参考：[CSDN 安装记录](https://blog.csdn.net/Skyrim0107/article/details/137513173)。

> **版本对应：** Ubuntu 22.04（Jammy）官方发行版是 **Humble**；**Foxy** 对应 Ubuntu 20.04。下面既保留了原稿中的 Foxy 步骤，也整理了后续 Humble / 鱼香 ROS 的用法。

## 一、推荐安装方式

不要在已有 conda 的环境里硬装。可采用[鱼香 ROS](http://fishros.com/install) 一键配置：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

添加 GPG 密钥（部分教程会用到）：

```bash
sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654
```

## 二、按步骤安装 ROS 2（原稿：Foxy）

### 2.1 安装依赖

```bash
sudo apt update && sudo apt upgrade
sudo apt install curl gnupg2 lsb-release wget
```

### 2.2 设置软件源

Ubuntu 22.04（Jammy）示例：

```bash
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(lsb_release -cs) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

### 2.3 安装桌面版

原稿安装的是 Foxy（更适合 20.04）。若系统是 22.04，请改成 `ros-humble-desktop`。

```bash
sudo apt update
sudo apt install ros-foxy-desktop
# Ubuntu 22.04 建议：
# sudo apt install ros-humble-desktop
```

### 2.4 环境变量

```bash
source /opt/ros/foxy/setup.bash
# Humble：source /opt/ros/humble/setup.bash
```

写入 `~/.bashrc` 后立即生效：

```bash
source ~/.bashrc
```

### 2.5 验证

```bash
ros2 --version
```

### 2.6 构建工具（可选）

```bash
sudo apt install python3-colcon-common-extensions
```

### 2.7 创建工作空间（可选）

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
source install/setup.bash
```

ROS 2 中不需要启动 `roscore`。`python3-roslaunch` 属于 ROS 1 工具链：

```bash
sudo apt install python3-roslaunch
```

## 三、colcon 编译

`colcon` 是 ROS 2 的编译工具（类似编译器角色）：

- `catkin` 支持 ROS 1
- `colcon` 支持 ROS 2

安装 ROS 2 时一般不会自带 colcon，需单独安装：

```bash
sudo apt-get install python3-colcon-common-extensions
```

常用编译选项：

```bash
colcon build --parallel-workers 4     # 只用 4 个内核
colcon build --executor sequential    # 顺序编译，不用并行
colcon clean                          # 清理构建产物
```

### 测试 colcon

```bash
mkdir colcon_test && cd colcon_test
git clone https://github.com/ros2/examples src/examples -b humble
sudo colcon build --executor sequential
source install/setup.bash

# 订阅节点
ros2 run examples_rclpy_minimal_subscriber subscriber_member_function
# 发布节点
ros2 run examples_rclcpp_minimal_publisher publisher_member_function
```

## 四、小海龟测试

```bash
ros2 run turtlesim turtlesim_node
ros2 run turtlesim turtle_teleop_key
```

另开终端输入 `rqt`，打开 **Plugins → Introspection → Node Graph**，查看节点关系。

## 五、常用查询命令

```bash
ros2 node list      # 节点列表
ros2 topic list     # 话题列表
ros2 action list    # 动作列表
ros2 service list   # 服务列表
```

## 六、其他备忘

添加 PPA：

```bash
sudo add-apt-repository ppa:someuser/someppa
sudo apt-get update
```

遇到类似错误时检查软件源 / PPA 是否匹配当前发行版：

```
0.8.10-7' for 'python3-catkin-pkg' was not found
```
