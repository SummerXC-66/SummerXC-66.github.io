Ubuntu 上安装 ROS 2、建工作空间 / 功能包，以及 colcon 编译和常用命令。

| Ubuntu | ROS 2 发行版 |
|--------|--------------|
| 22.04（Jammy） | **Humble**（当前推荐） |
| 20.04（Focal） | Foxy |

参考：[CSDN 安装记录](https://blog.csdn.net/Skyrim0107/article/details/137513173)、[Bilibili：是机器人饲养员](https://www.bilibili.com/read/cv42107510/?opus_fallback=1)。

## 一、安装前注意

不要在已有 conda 的环境里硬装 ROS。更省事的方式是[鱼香 ROS](http://fishros.com/install) 一键配置：

```bash
wget http://fishros.com/install -O fishros && . fishros
```

下面是官方软件源的手工安装步骤。

## 二、官方安装 ROS 2 Humble（Ubuntu 22.04）

### 2.1 设置 locale

```bash
sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

### 2.2 添加 ROS 2 仓库

```bash
sudo apt update && sudo apt install curl gnupg lsb-release
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(source /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

部分教程还会用 `apt-key` 加密钥（较旧写法）：

```bash
sudo apt-key adv --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654
```

### 2.3 安装桌面完整版

```bash
sudo apt update
sudo apt install ros-humble-desktop-full
```

只要桌面版、不要完整仿真栈时，可改用 `ros-humble-desktop`。

### 2.4 环境变量

```bash
source /opt/ros/humble/setup.bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
```

已写入 `~/.bashrc` 的终端再执行一次即可生效：

```bash
source ~/.bashrc
```

### 2.5 验证

```bash
ros2 --version
```

### 2.6 构建工具（可选）

安装 ROS 2 时一般不会自带 colcon，需单独安装：

```bash
sudo apt install python3-colcon-common-extensions
```

## 三、Foxy 备忘（Ubuntu 20.04）

原稿里装的是 Foxy，只适合 20.04。软件源添加方式与上面类似，安装和 source 换成：

```bash
sudo apt update
sudo apt install ros-foxy-desktop
source /opt/ros/foxy/setup.bash
```

## 四、工作空间与功能包

### 4.1 创建工作空间

```bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
source install/setup.bash
```

ROS 2 不需要启动 `roscore`。`python3-roslaunch` 属于 ROS 1 工具链，一般不必装：

```bash
sudo apt install python3-roslaunch
```

### 4.2 创建功能包

C++ 包（`ament_cmake`）：

```bash
ros2 pkg create --build-type ament_cmake my_robot_pkg \
  --dependencies rclcpp std_msgs sensor_msgs geometry_msgs
```

Python 包（`ament_python`）：

```bash
ros2 pkg create --build-type ament_python my_robot_pkg_py \
  --dependencies rclpy std_msgs sensor_msgs geometry_msgs
```

通常在工作空间的 `src/` 下执行上述命令，再回到工作空间根目录 `colcon build`。

## 五、colcon 编译

`colcon` 是 ROS 2 的编译工具：

- `catkin` 支持 ROS 1
- `colcon` 支持 ROS 2

常用选项：

```bash
colcon build --parallel-workers 4     # 只用 4 个内核
colcon build --executor sequential    # 顺序编译，不用并行
colcon clean                          # 清理构建产物
```

### 测试 colcon

```bash
mkdir colcon_test && cd colcon_test
git clone https://github.com/ros2/examples src/examples -b humble
sudo colcon build --executor sequential
source install/setup.bash

# 订阅节点
ros2 run examples_rclpy_minimal_subscriber subscriber_member_function
# 发布节点
ros2 run examples_rclcpp_minimal_publisher publisher_member_function
```

## 六、小海龟测试

```bash
ros2 run turtlesim turtlesim_node
ros2 run turtlesim turtle_teleop_key
```

另开终端输入 `rqt`，打开 **Plugins → Introspection → Node Graph**，查看节点关系。

## 七、常用查询命令

```bash
ros2 node list      # 节点列表
ros2 topic list     # 话题列表
ros2 action list    # 动作列表
ros2 service list   # 服务列表
```

## 八、其他备忘

添加 PPA：

```bash
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo add-apt-repository ppa:someuser/someppa
sudo apt-get update
```

遇到类似错误时，检查软件源 / PPA 是否匹配当前发行版：

```
0.8.10-7' for 'python3-catkin-pkg' was not found
```

装完或换机后确认源：

```bash
apt-cache policy | grep ros-humble
```

没有输出就按第二节重新加源。旧写法 `curl .../ros.asc | sudo apt-key add -` 不推荐。
