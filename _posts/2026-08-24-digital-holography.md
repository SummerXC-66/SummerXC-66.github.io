数字全息用探测器记下物光与参考光的干涉强度，再用数值衍射把振幅和相位一起再现出来。再现不必回到光路里，换传播距离就能对多层分别对焦。

下面两张图分别是层析法原理，以及一次离轴仿真的物面 / 再现总览。

## 一、层析法：记录与再现

物体沿轴向拆成若干平行物面 `O1, O2, O3`，各层到全息面的距离为 `z1, z2, z3`。记录时各层衍射场在全息面叠加，再与倾斜参考光干涉；再现时用照明光照射全息图，反向传播回各层原距离。

![层析法数字全息重建：记录过程与再现过程](/assets/images/digital-holography/layer-based-reconstruction.jpg)

图 (a) 记录：平面波照明多层物面，物光沿 z 传到全息面 `(ξ, η)`，倾斜参考光同时入射。图 (b) 再现：照明光照射全息图，再现波反向传到 `z1, z2, z3`，得到 `O'1, O'2, O'3`。

### 1. 菲涅尔衍射

第 i 层物面复振幅传到全息面：

```
E_i(ξ, η) = exp(j k z_i) / (j k z_i)
          · ∬ O_i(x_i, y_i) exp[j φ_i(x_i, y_i)]
            · exp{ j k / (2 z_i) · [(ξ - x_i)² + (η - y_i)²] } dx_i dy_i
```

物面坐标是 `(x_i, y_i)`，波数 `k = 2π / λ`。

### 2. 衍射叠加

各层衍射场在全息面相加，写成振幅和相位：

```
E(ξ, η) = Σ E_i(ξ, η) = A(ξ, η) exp[j Φ(ξ, η)]
```

### 3. 参考光

倾斜平面参考光把干涉条纹偏到一侧，再现时才能和直流项、共轭项分开：

```
R(ξ, η) = B(ξ, η) exp[j 2π (α ξ + β η)]
```

`α, β` 是参考光的空间载频。

### 4. 博奇编码得到全息图

计算机生成全息常用博奇（Burch）编码，把复振幅压成非负强度：

```
H(ξ, η) = 0.5 { 1 + A(ξ, η) cos[2π(α ξ + β η) − Φ(ξ, η)] }
```

光学记录则直接拍干涉强度 `|R + E|²`，再归一化后做数值再现。两者都是「强度里编码了物光相位」。

### 5. 参考光再现

全息图乘参考光后，按第 i 层距离做菲涅尔逆衍射：

```
O'_i(x_i, y_i) = exp(j k z_i) / (j k z_i)
               · ∬ H(ξ, η) R(ξ, η)
                 · exp{ j k / (2 z_i) · [(x_i − ξ)² + (y_i − η)²] } dξ dη
```

换 `z_i` 就换对焦层，这就是层析再现。

## 二、仿真总览：物面与再现

单层离轴仿真的结果。物面是中心一块矩形相位物体：振幅为 1，相位沿行线性扫描。倾斜平面参考光与衍射物光干涉，再沿 `-z0` 反向菲涅尔传播。

![物面相位 / 振幅与再现相位 / 振幅总览](/assets/images/digital-holography/overview.png)

| 位置 | 内容 | 看什么 |
|------|------|--------|
| 左上 | object phase | 方块内水平相位条纹 |
| 右上 | object amplitude | 中心透光方块，背景为 0 |
| 左下 | reconstructed amplitude | 离轴三分量：中心直流、一角实像、对角共轭像 |
| 右下 | reconstructed phase | 原相位条纹被找回，背景有散斑噪声 |

左下图里实像、共轭像、零级分开，是离轴数字全息的典型特征；载频 `α, β`（仿真里的 `Qx, Qy`）不够大时，三项会叠在一起。

## 三、和仿真代码的对应

`my/holo` 按同一条链路拆模块：物平面 → 菲涅尔正演 → 干涉全息 → 反向再现 → 存图。

| 步骤 | 文件 | 对应上文 |
|------|------|----------|
| 取样网格、波长、衍射距离 | `params.py` | `k`、`z0`、CCD / 物面宽度 |
| 中心矩形相位物体 | `object_plane.py` | `O_i exp(j φ_i)` |
| 菲涅尔正演 / 逆演 | `fresnel.py` | 第 1、5 节积分的 FFT 实现 |
| 倾斜平面参考光与干涉 | `hologram.py` | 第 3 节；记录用 `|R+E|²` |
| 全息图 × 参考光再反向传播 | `reconstruct.py` | 第 5 节 |
| 2×2 总览图 | `save_images.py` | 第二节 `overview.png` |

```bash
cd my/holo
conda run -n summer python main.py
```

结果写到 `output/`。第二节那张总览就是 `save_overview()` 的输出。
