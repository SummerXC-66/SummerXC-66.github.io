**RECAP**（RL with Experience and Corrections via Advantage-conditioned Policies）把 VLA 的强化学习改成「带优势标签的条件监督学习」。模型是 **π\*0.6**：在 π0.6 上多一个二值条件 `Advantage: positive / negative`。

论文：[π\*0.6: a VLA That Learns From Experience](https://arxiv.org/abs/2511.14759)

价值函数给经验打「比预期好 / 差」，策略两种都学；部署时只走 **positive**。

## 一、总流程

数据三种一起用：人类示范、自主 rollout（成败都留）、专家中途纠正。

```
示范 / 自主尝试 / 专家纠正
        ↓
价值函数：还要多久成功
        ↓
优势 = 实际进展 − 预期  →  Positive / Negative
        ↓
VLA 条件监督学习这两种模式
        ↓
部署只采样 Positive
        ↓
再采集 → 再训 value → 再训 policy（每轮都从预训练权重重启）
```

| 阶段 | 做什么 |
|------|--------|
| 预训练 | 在多任务示范上训 `V_pre`、`π_pre` |
| 下游 | 用任务示范初始化，从预训练权重微调（可先把标签全标成 positive，等于 SFT） |
| 迭代 | 上机采集并入数据；**从预训练 checkpoint** 重训 value 和 policy，不接着上一轮训，用来压 drift |

很多任务一轮就有提升。

## 二、五步

### 1. 稀疏奖励

每条 episode 只需成功 / 失败。`r_t`：成功结束为 `0`，失败结束为 `-C_fail`，中间步为 `-1`。成功轨迹的 return 就是「还要几步」的负数。不写稠密 reward。

### 2. 训价值函数

输入观测和语言指令，输出「离成功还有多远」（离散分布再取期望）。用 Monte Carlo return 做交叉熵。成功轨迹上价值升向 `0`，失败或卡死会掉下去。

### 3. 优势二值化

`A = 实际回报 − V(o)`。预训练用整条 return；微调用 n-step（约 50 步）。`I_t = 1(A > ε)`，`ε` 按任务分位数：预训练大约 30% 标 positive，微调约 40%；已经能做但太慢的任务可压到约 10%。**专家纠正强制 positive**。

### 4. 条件监督学习

不必对 log-prob 求导。文本前缀里加 `Advantage: positive` 或 `negative`，同时学有条件和无条件（类似 CFG）。正负样本都进训练：负样本学「不要这样做」。

### 5. 部署

默认喂 `Advantage: positive`。可选 CFG 把强度提到 1.5–2.5；太大动作会过猛。然后带着新策略回到第 1 步。

## 三、和 PPO / AWR 的差别

| 方法 | 问题 |
|------|------|
| PPO | flow matching 没有稳定 log-prob，真机接近 offline |
| AWR | 负样本被丢掉，等于 filtered BC |
| RECAP | **全部数据做监督**，只多一个正 / 负标签 |

## 四、π\*0.6 结构

仍是 Knowledge Insulation：Gemma 3 4B 做视觉语言、子任务和 FAST 离散动作；独立 860M action expert 做 50 Hz 连续动作，stop-gradient 避免污染 backbone。相对 π0.5：更多平台数据、更大 action expert，以及 RECAP 的 `I_t`。
