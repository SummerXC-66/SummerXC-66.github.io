**RECAP** 把 VLA 的强化学习改成带优势标签的条件监督学习。价值函数只负责打「比预期好 / 差」，策略两种都学；部署时只走 **positive**。

论文：[π\*0.6: a VLA That Learns From Experience](https://arxiv.org/abs/2511.14759)

## 一、思路

真机上 PPO 不好用：flow matching 没有稳定 log-prob，数据也接近 offline。AWR 又会丢掉负样本。RECAP 的做法是：**成败数据全部留下，只多一个文本条件**。

数据三类一起用：人类示范、自主 rollout（成功和失败都留）、专家中途纠正。

## 二、循环

```
采集（示范 / 自主 / 纠正）
    → 训价值：还要多久成功
    → 优势二值化：Positive / Negative
    → 条件监督训策略
    → 部署只采样 Positive
    → 再采集（每轮从预训练权重重训，不接着上一轮）
```

| 阶段 | 做什么 |
|------|--------|
| 预训练 | 多任务示范上得到 `V_pre`、`π_pre` |
| 下游 | 任务示范初始化；从预训练微调（标签可先全标 positive，等于 SFT） |
| 迭代 | 上机数据并入后，**从预训练 checkpoint** 重训 value 和 policy，用来压 drift |

多数任务一轮就有提升。

## 三、标签怎么来

| 步骤 | 做法 |
|------|------|
| 奖励 | 每条 episode 只标成功 / 失败。中间步 `-1`，成功结束 `0`，失败结束 `-C_fail`。不写稠密 reward。 |
| 价值 `V` | 输入观测和语言，输出「离成功还有多远」。Monte Carlo return + 交叉熵。成功轨迹升向 `0`，卡住会掉。 |
| 优势 | `A = 实际回报 − V(o)`。预训练用整条 return，微调用约 50 步 n-step。 |
| 二值 | `I_t = 1(A > ε)`。`ε` 按分位数：预训练约 30% positive，微调约 40%；能做但太慢可压到约 10%。**专家纠正强制 positive**。 |

## 四、策略与部署

训练：在动作前加前缀 `Advantage: positive` 或 `negative`，有条件和无条件一起学（类似 CFG）。负样本用来学「不要这样做」，不必对 log-prob 求导。

部署：默认喂 `positive`。可选 CFG 把强度提到 1.5–2.5，太大动作会过猛。然后带着新策略回到采集。

## 五、π\*0.6

Knowledge Insulation：Gemma 3 4B 做视觉语言、子任务和 FAST 离散动作；独立 860M action expert 做 50 Hz 连续动作，stop-gradient 避免污染 backbone。相对 π0.5：更多平台数据、更大 action expert，以及 RECAP 的 `I_t`。
