用 Hugging Face `transformers` 从本地目录加载 **Qwen3-VL-2B-Instruct**，作为理解专家（`und_expert`）。

```python
self.und_expert = Qwen3VLForConditionalGeneration.from_pretrained(
    "/home/summer/Desktop/summer/huggingface/models/Qwen/Qwen3-VL-2B-Instruct",
    config=vlm_config_hf,
    ignore_mismatched_sizes=True,
    torch_dtype=torch.float16,
)
```

| 参数 | 说明 |
|------|------|
| 模型路径 | 本机已下载的 `Qwen3-VL-2B-Instruct` 目录 |
| `config` | 传入已准备好的 `vlm_config_hf` |
| `ignore_mismatched_sizes=True` | 权重与配置尺寸不一致时仍继续加载 |
| `torch_dtype=torch.float16` | 半精度，省显存 |

加载前需已安装对应版本的 `transformers`，并保证该路径下有完整的模型文件与配置。
