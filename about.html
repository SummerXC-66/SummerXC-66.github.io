关于本站

这是我的个人学习记录站点，用来保存学习过程中的笔记、心得和参考资料，方便随时浏览和回顾。

如何添加新笔记

在仓库的 _posts/ 目录下创建 Markdown 文件，命名格式为：

YYYY-MM-DD-标题.md

文件开头需要包含以下信息（Front Matter）：

---
layout: post
title: 笔记标题
date: 2026-07-11
category: 编程
tags: [Git, GitHub]
---

这里是笔记正文，支持 **Markdown** 语法。

部署到 GitHub Pages

  1. 在 GitHub 上创建仓库（推荐命名为 你的用户名.github.io）
  2. 将本仓库代码推送到 GitHub
  3. 进入仓库 Settings → Pages
  4. Source 选择 Deploy from a branch，Branch 选 main，文件夹选 / (root)
  5. 等待几分钟，访问 https://你的用户名.github.io

本地预览

安装 Ruby 和 Bundler 后，在项目目录运行：

bundle install
bundle exec jekyll serve

然后打开 http://localhost:4000 预览。
